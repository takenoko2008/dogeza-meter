# 土下座メーター - オンライン対戦版

ルームコードを使って、別の端末にいる相手と土下座で勝負できます。
判定は**カメラ判定のみ**（マウス操作モードは廃止）です。他の端末からでもカメラが使えるよう、
簡易HTTPS（自己署名証明書）にも対応しています。

## 使い方

```bash
npm install
npm start
```

起動するとターミナルに以下のように表示されます（IPは環境によって変わります）。

```
[このPCで開く]
  http://localhost:3000

[他の端末から参加（カメラを使うには必ずこちら）]
  https://192.168.1.23:3443
```

- 自分のPCだけで試すなら `http://localhost:3000` でOKです。
- 友達のスマホ・PCから参加してもらう場合は、同じWi-Fiに接続した状態で
  `https://192.168.x.x:3443`（LAN IP）を開いてもらってください（カメラ判定は`https`か`localhost`
  でしか動かないブラウザの仕様のため、必ずこちらのアドレスを使う必要があります）。
  初回アクセス時にブラウザが「この接続はプライベートではありません」といった警告を出しますが、
  自分たちで立てたローカルサーバーなので、**「詳細設定」→「（安全でないサイトに）アクセスする」**
  で進んで問題ありません。

## 対戦の流れ

1. 名前を入力し、カメラを起動して基準をとる
2. 「対戦モード」で **🌐 オンライン対戦** を選ぶ
3. 「オンライン対戦へ進む」→「ルームを作る」を押すと4桁のルームコードが発行される
4. そのコードを相手に伝える（口頭・チャットなど）
5. 相手も同じサーバーのページ（`https://`）を開き、カメラの基準をとってから
   「ルームコードで参加する」にコードを入力して「参加する」
6. 両者が揃うと自動的にゲーム開始。プレイ中はお互いの角度・ラウンド進捗がリアルタイムで見える
7. 両者が3ラウンドを終えると、スコア比較画面で勝者が発表される

### 対戦タイプ（HPバトル / 謝罪対戦）

オンライン対戦の「ルームを作る」画面で、対戦タイプを選べます。ルームを作った人（ホスト）の
選択がそのルームに適用され、コードで参加したゲスト側にも自動的に反映されます。

- **⚔️ HPバトル**：お互いHP100からスタートし、画面下部にHPバーが表示されます。土下座の「勢い」
  （角度をどれだけ素早く・大きく動かしたか）に応じて相手にダメージが入ります。ゆっくり動くよりも
  勢いよく一気に頭を下げた方が大きなダメージになります（カメラ判定・声の謝罪ボーナスどちらもダメージ
  対象）。ラウンドクリアでもボーナスダメージ。どちらかのHPが0になった瞬間、その場でKO決着になります
  （3ラウンド消化を待ちません）。HPが0にならないまま両者が3ラウンドを終えた場合は、スコアと残りHPで
  勝敗が表示されます。ダメージを与えた／受けた瞬間は画面フラッシュ・カメラの揺れ・「Nダメージ！」の
  表示でわかりやすく演出されます。
- **🙏 謝罪対戦（スコア比較）**：ダメージやHPは無く、これまで通り3ラウンドの誠意スコアだけで
  勝敗を決める、じっくり系の対戦です。

## 注意点

- このアプリは**カメラ判定のみ**です。ブラウザのセキュリティ制約上 `localhost` または `https` でしか
  動作しません。これはこのアプリの制限ではなくブラウザ全体の仕様です。
- HTTPS用の証明書は起動のたびにサーバーが自動生成する**自己署名証明書**です。正式な証明書ではないため
  ブラウザに警告が出ますが、身内だけで使うローカルサーバーなので安全に無視して進めて構いません。
- `selfsigned` パッケージが読み込めない環境では、HTTPSサーバーの起動をスキップします（その場合カメラは
  localhost以外で使えません）。
- サーバーはルームコードの発行と、進捗・結果メッセージの中継のみを行います。採点ロジックや演出はすべて
  各プレイヤーのブラウザ側で動いています。
- ランキング（🏆）は各端末のブラウザ内（localStorage）に保存される、あくまでその端末だけの記録です。
  全員共通のランキングではありません。
- ルームは2人埋まった時点で締め切られます。どちらかが切断すると相手に通知され、ロビーに戻ります。

## ファイル構成

```
dogeza-online/
  package.json
  server.js          Node.js + ws + selfsigned によるルーム管理／中継サーバー（http & https 両対応）
  public/
    index.html       アプリ本体（HTML/CSS/JS）
    assets/
      dogeza-illustration.jpeg  下部バナーのイラスト
      bgm.mp3                   BGM
```

## BGM

画面右上の🔊ボタンでBGMのON/OFFを切り替えられます（設定はブラウザに記憶されます）。
ブラウザの自動再生制限により、ページを開いた直後は音が鳴らず、最初にどこかをクリック／タップ
した瞬間に再生が始まります。
